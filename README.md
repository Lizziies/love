# Love

An animated heart made of glowing particles. The website has no visible text, buttons or color controls.

## Run locally

Open `index.html` in a modern browser. The site is static and requires no dependencies or build step.

## GitHub Pages

In this repository, open **Settings → Pages** and set:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

The website is published at <https://lizziies.github.io/love/> after the Pages deployment finishes.
